Runtime mode

The address your school already uses in a browser. It must start with https:// (or http:// on a local network).

This creates the first sign-in for the school's own database on this computer. It is stored in the operating system's keychain, never in plain text.

  • Data stays in this computer's EduSphere data folder and is backed up automatically.
  • Phones and tablets on the same Wi-Fi open the address shown after start-up (with a QR code to scan).
  • Your firewall may ask for permission — choose Allow on private networks.
